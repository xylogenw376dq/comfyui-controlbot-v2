# Справочник команд

Ноду в командах `/set`, `/params`, `/unset` можно указывать тремя способами:
ID (`57:80`), классом (`KSamplerAdvanced`) или частью названия/ID (`ksampler`, `80`).

## Генерация

| Команда | Описание |
|---|---|
| `/generate <текст>` | Поставить активный workflow в очередь. В img2img — вместе с фото (картинка в том же сообщении или reply) |
| `/prompt <текст>` | Запомнить промпт; `/generate` без аргументов использует его |
| `/regen` | Повторить последнюю генерацию с новым seed |
| `/last` | Переслать последний результат |

## Workflow

| Команда | Описание |
|---|---|
| `/workflow` | Текущий и доступные workflow |
| `/workflow <имя>` | Переключить (txt2img / img2img / свои из config.json) |

## Параметры workflow

| Команда | Описание |
|---|---|
| `/nodes` | Список нод (ID, класс, заголовок) |
| `/params <нода>` | Параметры ноды, эффективные значения, варианты combo |
| `/set <нода>.<параметр> <значение>` | Изменить параметр (валидация по /object_info) |
| `/set <параметр> <значение>` | То же, если имя параметра уникально |
| `/unset <нода>.<параметр>` | Сбросить один параметр |
| `/settings` | Все переопределения |
| `/reset` | Сбросить все переопределения |

Шорткаты: `/steps 8`, `/cfg 1`, `/width 1024`, `/height 1720`, `/batch 4`,
`/sampler res_multistep`, `/scheduler simple`, `/denoise 0.65`.

Значения валидируются: числа проверяются на диапазон и конечность, combo-списки —
с частичным совпадением (`/set sampler res_multi` → `res_multistep`).

## Seed

`/seed 12345` — зафиксировать · `/seed random` — случайный каждый запуск ·
`/seed increment` / `/seed decrement` — инкремент/декремент.
Понимает ноду `AdvancedSeedGenerator` (переключает её `mode`) и скалярные seed-параметры.

## ControlNet (txt2img и img2img)

| Команда | Описание |
|---|---|
| `/cnet` | Статус |
| `/cnet on` / `/cnet off` | Включить/выключить |
| `/cnet mode <имя>` | Режим-препроцессор: `bones`, `depth`, `canny`, `hed`, `mlsd`… Полный список: `/cnet mode list` |
| `/cnet strength 0.8` | Сила контроля |
| `/cnet clear` | Удалить одобренную маску |
| фото с подписью `/cnet` | Загрузить референс → бот присылает маску → кнопки ✅/✖️ |

Одобренная маска используется во всех генерациях до `/cnet clear`.

## LoRA

| Команда | Описание |
|---|---|
| `/lora` | Статус |
| `/lora list` | Список алиасов (✅ файл есть / ❌ нет) |
| `/lora <имя>` | Выбрать (действует до `/lora off` или смены) |
| `/lora strength 0.8` | Сила (model + CLIP) |
| `/lora off` | Выключить |

## Сервер

`/status` — версия, RAM/VRAM, очередь, здоровье бота · `/queue` · `/stop` · `/clearqueue` ·
`/last` — переслать последний результат · `/regen` — повтор с новым seed.

## Пользователи

| Команда | Описание |
|---|---|
| `/id` | Свой ID и ID чата (доступно всем) |
| `/users` | Список (админ) |
| `/adduser <ID>` | Дать доступ; можно reply на сообщение (админ) |
| `/deluser <ID>` | Забрать доступ (админ) |

## Язык

`/lang` — текущий язык · `/lang en` / `/lang ru` — сменить (в группах — только админы).
