# Тесты

## Офлайн-тесты

`tests/test_daemon_offline.py` — логика команд без сети: Telegram API и ComfyUI
замещаются фейками. Запуск из папки плагина:

```
python tests/test_daemon_offline.py
```

Покрывают: парсинг команд, валидацию значений, переопределения, seed-режимы,
инъекцию LoRA/ControlNet (включая порядок цепочки), маску и её одобрение,
скачивание файлов с ретраями, ws-слушатель прогресса, пользователей и админов,
локализацию (включая автопроверку i18n-покрытия ключей), watchdog, доставку альбомов.

Тесты изолированы от боевых данных: хранилища подменяются временными файлами.

## E2E-скрипты

Взаимодействуют с живым ComfyUI и реальным Telegram-чатом (заглушка — только
скачивание файла из Telegram):

- `tests/test_e2e_delivery.py` — img2img-альбом из двух картинок
- `tests/test_e2e_img2img.py` — полная img2img-генерация
- `tests/test_e2e_cnet.py` — маска ControlNet + генерация по ней

Запуск тем же python из окружения ComfyUI. Отправляют реальные сообщения
в чат первого пользователя из `allowed_users`.
